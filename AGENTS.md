# wennstrom-fi-public

Tämä repo on `wennström.fi`-sivuston julkinen Astro-lähde. Sivujen lisäämisen
työnkulku ja tekniset perustelut ovat [README:ssä](README.md#uuden-tavallisen-sivun-lisääminen).
Keskeneräisen työn jatkokohta on paikallinen `NEXT_SESSION.md`, jos se on saatavilla;
varmista aina myös elävä Git-tila.

Kun Codex lisää tai päivittää tavallista sivua, siihen kuuluu README:n mukaisesti
myös sisällöstä perusteltu otsikko ja yksilöllinen metakuvaus, yhteisen `PageLayout`-
sivupohjan käyttö, luontevat sisäiset linkit sekä `npm run build` -tarkistus.
Tee nämä osana samaa sivutyötä. Käyttäjän ei tarvitse toimittaa erillisiä SEO-kenttiä
tai muistuttaa linkityksestä. Kysy vain sisällöstä tai sivuston nykyisestä rakenteesta
ratkeamattomat olennaiset valinnat. Säilytä käyttäjän antamat otsikot ja muut
sisältövalinnat; älä kirjoita julkaistuja keskusteluja uudelleen metatietojen vuoksi.

Pidä tekniset ohjeet README:ssä ja käytä olemassa olevaa build-automaatiota.
Push ja julkaisu vaativat käyttäjän erillisen hyväksynnän.

Codex laati tämän projektiohjeen käyttäjän täsmentämän työnjaon perusteella.
